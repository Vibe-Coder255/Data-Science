# What is Time Complexity ?

Rate of increase in time with respect to input size is called as Time Complexity.


# Rules

1. Always calculate Time Complexity in terms of worst case.
2. Avoid the constant values.
3. Avoid lower bound.

# Different Types of Time Complexity

1. Worst-Case Complexity (\[O\] - Big O Notation) - Upper Bound
2. Average-Case Complexity (Θ - Theta Notation)
3. Best-Case Complexity (Ω - Omega Notation) - Lower Bound


# Space Complexity

Memory Space to run a program.

* It consists of two thing : ``Auxiliary Space + Input Space``

* Auxiliary Space : The extra space used to solve the problem.
* Input Space : The space used to store the input.
