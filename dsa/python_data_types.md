# Python Data Types

| Type | Class | Description | Example |
| :--- | :--- | :--- | :--- |
| **Integer** | `int` | Whole numbers without decimals | `age = 25` |
| **Floating-Point** | `float` | Numbers with a decimal point | `price = 19.99` |
| **String** | `str` | Text enclosed in single, double, or triple quotes | `name = "Alice"` |
| **Boolean** | `bool` | Logical values that are either `True` or `False` | `is_active = True` |
| **List** | `list` | An ordered, mutable (changeable) collection of items | `items = [1, "apple", 3.4]` |
| **Tuple** | `tuple` | An ordered, immutable (unchangeable) collection | `point = (10, 20)` |
| **Dictionary** | `dict` | A collection of unique key-value pairs | `user = {"id": 1, "role": "admin"}` |
| **Set** | `set` | An unordered collection of unique elements | `unique_ids = {1, 2, 3}` |
